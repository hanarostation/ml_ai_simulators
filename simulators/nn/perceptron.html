퍼셉트론 시뮬레이터

노드 하나는 입력에 가중치를 곱해 더하고(Σ) 활성 함수를 거쳐 출력합니다. 가중치로 논리 게이트를 만들고, 틀린 점을 만날 때마다 경계선이 움직이는 학습 규칙을 따라가 본 뒤, 직선 하나로는 안 되는 XOR을 은닉층으로 푸는 과정과 활성 함수가 비선형이어야 하는 이유를 확인합니다.

입력 · 가중치 · bias

예시: 발열 · 기침 · 호흡곤란 증상으로 검사 필요 여부를 정하는 노드

입력
활성 함수

노드 하나: 가중합 Σ → 활성 함수 → 출력 y

양수 가중치음수 가중치선 굵기 = |w|순전파

활성 함수 그래프

점 = 지금의 z

모든 증상 조합 8가지

같은 w · b · 활성 함수

네 활성 함수 모두 z > 0 이면 "필요" 쪽입니다 (계단 1, 시그모이드 0.5 초과, tanh 0 초과, ReLU 0 초과). 다른 것은 출력의 모양입니다: 0/1 결정, 0~1 확률, −1~1, 0 이상 크기.

게이트 맞히기

입력 2개, 계단 함수

입력 평면과 결정 경계 w₁x₁ + w₂x₂ + b = 0

정답 1정답 0ŷ = 1 영역ŷ = 0 영역빨간 고리 = 틀림

퍼셉트론 학습 규칙: 틀린 점을 만날 때만 고친다

키보드 → 한 샘플 · ← 이전
ŷ = step(w₁x₁ + w₂x₂ + b) (z > 0 이면 1, 아니면 0) w ← w + η(y − ŷ)x b ← b + η(y − ŷ) 맞히면 y − ŷ = 0 → 그대로 · 1인데 0이라 하면 +ηx 쪽으로 · 0인데 1이라 하면 −ηx 쪽으로

퍼셉트론 수렴 정리(Novikoff, 1962): 데이터가 직선으로 나뉘면(선형 분리 가능) 갱신은 유한 번, 최대 (R/γ)²번 뒤 반드시 멈춘다. R = 가장 먼 점까지 거리, γ = 경계와 가장 가까운 점 사이 여백.
