Offline RL (CQL · IQL)

새로 실험할 수 없을 때, 이미 쌓인 기록(과거 진료 로그)만으로 정책을 학습합니다. 데이터에 없는 행동을 과대평가하는 분포 이동 문제를 직접 보고, CQL·IQL이 데이터 범위 안에 머무르며 이를 피하는 과정을 숫자로 따라갑니다.

온라인 RL과 오프라인 RL

상태 = 파랑 · 행동 = 주황 · 보상 = 초록 · 가치 = 보라

치료 경로 격자 — 왼쪽 아래 S(입원)에서 오른쪽 아래 G(회복·퇴원)까지 가는 문제입니다. 하루(한 걸음)마다 보상 −1, 아래 줄 H는 공격적 치료의 중증 합병증(보상 −100, 종료)입니다. 위쪽 길은 안전하지만 오래 걸리고, H 바로 위 길이 가장 빠릅니다. 행동은 0↑ 1→ 2↓ 3← 네 가지, γ = 0.99, 한 에피소드 최대 50걸음.

오프라인 RL의 성패는 데이터 범위(coverage)에 달려 있습니다. 전문가 기록은 좋은 길만 촘촘히 덮고 나머지는 비어 있고, 무작위 기록은 넓게 덮지만 좋은 길이 드뭅니다. 빈 칸(빨간 점선)의 결과는 데이터로 알 수 없습니다.

max는 가장 큰 값을 고릅니다. 데이터에 없는 행동의 Q는 한 번도 고쳐지지 않아 초기값(0)이나 외삽된 값이 그대로 남고, 실제 값(음수)보다 커서 max에 뽑힙니다. 이 과대추정이 앞 상태로 번지고(bootstrapping), 정책은 데이터 밖 행동을 고르며, 그 결과는 데이터로 확인할 수 없습니다. 실제 실행 결과는 제자리 맴돌기나 합병증입니다.

CQL — 데이터에 없는 행동의 Q를 눌러 내리기

Conservative Q-Learning
L(Q) = α · Es~D[ log Σa exp Q(s,a) − Ea~D Q(s,a) ] + ½ · E(s,a,r,s′)~D[ (Q(s,a) − (r + γ·maxa′Q(s′,a′)))² ]
앞 항: 모든 행동의 Q를 부드럽게 최대(log-sum-exp)로 누르고 데이터 행동의 Q는 올림 → 데이터 밖 행동만 내려감 · 뒤 항: 보통의 벨만 오차
반복 0
탐욕 행동데이터에 없는 행동(눌러 내림)데이터에 없는 상태실행 경로

선택한 상태의 CQL 벌점

0실제 리턴
0추정 V̂(S)
0실제 최적 V*(S)
0데이터 밖 행동 횟수
실제 리턴 (탐욕 정책 실행)
추정 V̂(S) — 점선 = 실제 최적 V*(S)

α = 0이면 단순 Q 학습과 같아 데이터 밖 행동이 0 근처에 남아 실패합니다. α를 키우면 데이터 밖 행동의 Q가 실제보다 크게 낮아지고(보수적), 데이터에 자주 나온 행동의 Q는 조금 올라가 정책이 데이터 범위 안에 머뭅니다. α가 너무 크면 데이터에 자주 나온 행동만 고르는 행동 복제(BC)에 가까워집니다.

IQL — max를 쓰지 않는 표본 내(in-sample) 학습

Implicit Q-Learning
① V 학습: LV = E(s,a)~D[ L2τ( Q(s,a) − V(s) ) ],   L2τ(u) = |τ − 1(u<0)| · u²  (기대분위 회귀)
② Q 학습: LQ = E(s,a,r,s′)~D[ ( r + γ · V(s′) − Q(s,a) )² ]  ← max 대신 V(s′): 데이터에 없는 행동을 아예 쓰지 않음
③ 정책 추출: π(a|s) ∝ πβ(a|s) · exp( β · (Q(s,a) − V(s)) )  (이점 가중 회귀, AWR)
반복 0
비대칭 손실 L₂^τ(u) — 보라 = 현재 τ, 회색 점선 = τ 0.5(보통 제곱)

u = Q − V > 0 (V보다 좋은 행동)에는 τ, u < 0에는 1−τ 무게를 줍니다. τ가 1에 가까울수록 V는 데이터에 있는 행동들 중 최댓값에 다가갑니다. 점 = 선택한 상태의 u 값.

칸 숫자 = V(s)데이터에 없는 상태화살표 = π(a|s) (데이터에 있는 행동만)

선택한 상태의 계산

0실제 리턴
0V(S)
0데이터 밖 행동 횟수

IQL은 학습 내내 데이터에 실제로 있는 (s,a)의 값만 씁니다. τ = 0.5이면 V는 행동 정책의 평균(SARSA와 비슷), τ → 1이면 데이터 안에서의 max가 되어, 데이터 밖을 건드리지 않고도 행동 정책보다 나은 길을 찾습니다.
