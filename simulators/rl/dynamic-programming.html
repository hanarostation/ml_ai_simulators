동적 계획법 (Policy Iteration · Value Iteration)

정책 반복 (Policy Iteration) — 평가 ⇄ 개선
→ 키: 다음 단계 (평가 1 sweep 또는 개선 1번)

      

        ① 정책 평가: 모든 s에 대해 V(s) ← Σa π(a|s) Σ p · [ r + γ V(s′) ] 를 Δ = max|V새 − V| < θ 일 때까지 반복 (sweep)

        ② 정책 개선: π(s) ← argmaxa q(s, a) (같으면 기존 행동 유지) → 바뀐 칸이 없으면 정책 안정 = 최적
      

      
  1. ① 정책 평가
  2. ② 정책 개선
  3. ③ 정책 안정 (종료)
