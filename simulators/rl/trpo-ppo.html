TRPO → PPO (정책 업데이트 폭 제한)

정책 경사의 한 걸음이 너무 크면 성능이 무너집니다. 중요도 비율과 대리 목적, TRPO의 KL 신뢰 영역(자연 경사·켤레 기울기·선 탐색), PPO의 클리핑을 작은 문제에서 숫자로 확인하고, 브라우저에서 CartPole을 PPO로 직접 학습시키며 approx KL·clip fraction·엔트로피·설명 분산을 관찰합니다. 마지막으로 같은 PPO가 RLHF에서 LLM을 다듬는 방식까지 연결합니다.

정책 경사의 함정 — 한 걸음이 너무 크면 무너진다

짧은 복도 문제 (Sutton & Barto 예제 13.1)

정책 경사는 "지금 정책 근처에서" 성능이 오르는 방향만 알려 줍니다. 학습률을 크게 잡아 멀리 뛰면 그 방향이 더는 맞지 않아 성능이 오히려 무너지고, 무너진 정책이 모은 데이터로는 다시 회복하기도 어렵습니다. TRPO와 PPO는 모두 이 문제를 풀기 위해 "정책이 한 번에 바뀌는 폭"을 제한합니다.

에이전트–환경 루프와 정책 업데이트

짧은 복도: 상태 1에서는 행동이 반대로 작동

J가 −100보다 낮으면 그래프에서 −100으로 잘라 표시합니다. 1차원에서 피셔 정보는 F = p(1−p)이고, KL 한도 걸음은 |Δθ| = √(2δ / F)에서 시작해 실제 KL이 δ 이하이고 J가 오를 때까지 절반씩 줄입니다.

옛 정책으로 모은 데이터로 새 정책을 평가하기

치료 선택 문제 · 행동 3개 · 파라미터 2개

PPO·TRPO는 π_old로 한 번 모은 배치를 여러 번 재사용합니다. 새 정책 π_θ의 좋고 나쁨을 그 배치로 재려면 각 표본에 중요도 비율 r(θ) = π_θ(a|s) / π_old(a|s)를 곱합니다. 정책: π_θ = softmax(θ_A, θ_B, 0) — 치료 C의 점수는 0으로 고정. 실제 평균 회복 점수는 A 0.55 · B 0.75 · C 0.25 (학습자는 모름).

배치

표본별 계산 (π_old = 균등 1/3 · 기준선 b = 배치 평균 보상)

α를 키우며 본 대리 목적 vs 실제 개선

L̂(θ) = 평균 r·A (배치 추정)실제 J(θ) − J(θ_old)
KL(π_old ‖ π_new)유효 표본 비율 ESS/N

θ = θ_old에서는 모든 r = 1이고 ∇L(θ_old) = 평균 A·∇log π_old = 정책 경사 ĝ와 똑같습니다(위 수식의 두 숫자 비교). 즉 대리 목적은 정책 경사를 "옛 데이터로 계속 쓸 수 있게" 만든 식입니다. 멀어질수록 몇몇 표본의 r이 커져 추정이 소수 표본에 좌우되고(유효 표본 비율 ↓), 상태가 여러 개인 문제에서는 새 정책이 방문할 상태 분포가 달라지는 효과까지 빠집니다.

TRPO 논문의 하한: J(π_new) ≥ J(π_old) + L(π_new) − C · max_s KL(π_old ‖ π_new). 대리 목적 L을 올리되 KL을 작게 유지하면 실제 성능 개선이 보장된다는 뜻입니다 → TRPO는 KL을 제약으로, PPO는 비율 r을 클리핑하거나 KL을 벌점으로 넣습니다.

TRPO — KL 신뢰 영역 안에서 가장 좋은 걸음

최대화 L(θ) · 제약 KL(π_old ‖ π_θ) ≤ δ

2번 탭의 치료 선택 정책(파라미터 θ_A, θ_B)을 그대로 씁니다. 바탕색은 실제 기대 보상 J(θ), 분홍 닫힌 곡선은 θ_old에서 KL이 정확히 δ가 되는 경계(신뢰 영역), 회색 점선은 그 2차 근사 ½Δθᵀ F Δθ = δ 입니다. 평면을 클릭하면 θ_old를 옮길 수 있습니다. 이 탭은 기대값으로 정확히 계산합니다(표본 잡음 없음).

평면 위에 마우스를 올리면 그 점의 π, J, KL(π_old‖π)을 보여 줍니다.

① 경사 g와 피셔 행렬 F (θ_old에서)

실제 TRPO는 파라미터가 수만~수백만 개라 F를 만들 수 없습니다. 대신 KL의 헤시안–벡터 곱 F·v만 자동미분으로 계산해 CG(보통 10회)에 넣고, 마지막에 선 탐색으로 "실제 KL ≤ δ, 대리 목적 개선 > 0"을 확인합니다. 정확하지만 구현이 복잡하고 계산이 무거운 것이 TRPO의 약점 → PPO가 1차 미분만으로 비슷한 효과를 냅니다.

LCLIP = E[ min( r·A , clip(r, 1−ε, 1+ε)·A ) ]

PPO 논문의 대표 그림 · 표본 1개 기준

A > 0 (좋았던 행동, A = +1)

A < 0 (나빴던 행동, A = −1)

r·A (클립 없는 대리 목적)LCLIP기울기 0 구간 (더 가도 이득 없음)

A > 0이면 그 행동 확률을 올리고 싶지만 r이 1+ε를 넘으면 목적이 평평해져 더 올릴 유인이 사라집니다. A < 0이면 확률을 내리되 r이 1−ε 아래로 가면 멈춥니다. 반대로 나빠지는 방향(A>0인데 r↓, A<0인데 r↑)은 min 때문에 클립되지 않고 그대로 벌을 받습니다 → LCLIP은 r·A의 비관적 하한.

GAE 계산 따라가기 (가장 최근 롤아웃의 끝부분)

뒤에서부터: A_t = δ_t + γλ · A_{t+1}

δ_t = r_t + γ·V(s_{t+1}) − V(s_t)는 한 걸음 TD 오차입니다. GAE는 이것을 (γλ)의 거듭제곱으로 할인해 더합니다. λ = 0이면 한 걸음 TD, λ = 1이면 몬테카를로 이점. 에피소드가 끝난(넘어진) 걸음에서는 V(s_{t+1}) = 0이고 사슬이 끊깁니다. 500걸음 시간 제한으로 끝난 경우에는 마지막 상태의 V로 부트스트랩합니다.

브라우저 버전은 계산을 줄이려고 은닉층 32·32를 씁니다(SB3 기본값은 64·64). 행동은 CartPole과 같이 0 = 왼쪽, 1 = 오른쪽입니다.
