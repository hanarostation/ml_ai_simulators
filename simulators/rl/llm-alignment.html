LLM 정렬 (RLHF · DPO · GRPO)

아주 작은 언어 모형을 브라우저에서 직접 학습해 SFT → 보상 모델 → PPO · DPO · GRPO를 차례로 돌려 봅니다. 환자 안내 문구의 정확성 · 안전성 · 친절을 기준으로 보상 해킹, KL 계수 β, 그룹 상대 이점을 숫자로 확인합니다.

상자를 누르면 해당 화면으로 이동

사전학습으로 말을 배우고, SFT로 지시를 따르게 한 뒤, 사람의 선호를 이용해 "더 나은 답"을 고르도록 다듬는다. 세 갈래(RLHF·DPO·GRPO)는 선호 신호를 정책에 전달하는 방법이 다르다.

RLHF (PPO) — 선호 쌍으로 보상 모델을 만들고, 정책이 직접 응답을 생성하며 "보상 − β·KL"을 최대화. 정책·기준·보상·가치 네 모형이 필요.

DPO — 보상 모델과 생성 없이, 선호 쌍의 로그 확률 비율만으로 바로 분류 손실을 최소화. 정책·기준 두 모형.

GRPO — 질문마다 응답 G개를 뽑아 그룹 평균과 비교한 상대 점수로 학습. 가치망이 없고, 정답·형식처럼 검증 가능한 보상과 잘 맞는다.

    DPO — 보상 모델 없이 선호 쌍으로 바로 최적화

    Direct Preference Optimization
    KL 제약 최적 정책: π*(y|x) ∝ πref(y|x)·exp( r(x,y)/β )  ⇒  r(x,y) = β·log( π*(y|x)/πref(y|x) ) + β·log Z(x)
    Bradley–Terry에 대입하면 Z(x)가 사라진다:
    LDPO = −log σ( β·[ (log πθ(yw|x) − log πref(yw|x)) − (log πθ(yl|x) − log πref(yl|x)) ] )
    암묵적 보상 r̂(x,y) = β·log( πθ(y|x)/πref(y|x) )  ·  log π(y|x) = Σt log π(yt|x, y<t)

    메모리에 올리는 모형 2개: 정책 πθ(학습) · 기준 πref(고정). 응답을 새로 생성하지 않는 오프라인 학습 — 보상 모델 탭과 같은 선호 쌍 320개를 그대로 쓴다.

    GRPO — 그룹 안에서 비교한 상대 점수

    Group Relative Policy Optimization
    질문 x마다 응답 G개 {o1 … oG} ∼ πθ,old, 보상 ri  ⇒  Ai = ( ri − mean(r) ) / std(r)  (응답의 모든 토큰에 같은 Ai)
    J = (1/G) Σi (1/|oi|) Σt [ min( ρi,tAi, clip(ρi,t, 1−ε, 1+ε)Ai ) − β·DKL ]
    DKL = πref/πθ − log(πref/πθ) − 1  (토큰별 k3 추정량, 항상 ≥ 0)

    가치망(critic) 대신 그룹 평균이 기준선 역할을 한다. 메모리에 올리는 모형: 정책 · 기준 (+ 보상 모델을 쓰면 3개). 정답·형식처럼 규칙으로 채점할 수 있는 검증 가능한 보상이면 보상 모델도 필요 없다 — DeepSeek-R1-Zero가 수학 정답 일치 + 형식 보상만으로 학습한 방식.
