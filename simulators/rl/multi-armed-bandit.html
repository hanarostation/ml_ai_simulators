Multi-armed Bandit (ε-greedy · UCB · Thompson Sampling)

성공률을 모르는 여러 치료법(팔) 가운데 하나를 매번 골라 결과를 보고 배우는 문제입니다. 세 가지 알고리즘이 탐험과 활용의 균형을 어떻게 잡는지 한 걸음씩 따라가고, 여러 번 반복한 누적 후회로 비교합니다.

환경 설정

모든 탭이 같은 환경을 씁니다 · 바꾸면 처음부터 다시 계산
상황
seed

에이전트–환경 루프

상태가 하나뿐인 강화학습
목표
T번 동안 누적 보상 Σ rₜ 최대
가치
q*(a) = E[r | a] = p_a
후회(regret)
T·p* − Σ p_aₜ

탐험(Exploration): 덜 해 본 팔을 당겨 정보를 모은다. 활용(Exploitation): 지금까지 가장 좋아 보이는 팔을 당긴다. 한 번 당길 때 둘 중 하나만 할 수 있으므로 균형이 필요합니다.

적응형 임상시험(adaptive trial)을 단순화한 교육용 예시입니다. 실제 환자 배정에는 윤리 심의, 사전 등록된 통계 설계, 안전성 중간 분석이 필요합니다.

직접 당겨 보기

카드를 누르면 그 팔을 한 번 당깁니다
최근 기록

표본 평균 Q(a) = 성공 수 / 시도 수. 몇 번만 당기면 운에 크게 흔들립니다. 성공률을 공개해 추정이 얼마나 빗나가는지 확인해 보세요.

ε-greedy — 확률 ε로 탐험, 나머지는 활용

→ 키: 다음 걸음
aₜ = 무작위 팔 (확률 ε) · argmaxa Q(a) (확률 1 − ε)
N(a) ← N(a) + 1 , Q(a) ← Q(a) + ( r − Q(a) ) / N(a) … 표본 평균을 저장 없이 한 번에 갱신 (증분 평균)

팔별 추정값 Q(a)

Q(a)실제 p (에이전트는 모름)이번 선택

이번 걸음

누적 평균 보상

점선 = 최적 팔의 성공률 p*

누적 후회

Σ (p* − p_aₜ) · 낮을수록 좋음

UCB — 불확실한 팔에 보너스를 얹어 낙관적으로 고른다

→ 키: 다음 걸음
aₜ = argmaxa [ Q(a) + c · √( ln t / N(a) ) ] , N(a) = 0 이면 보너스 = ∞ (먼저 한 번씩)
많이 당긴 팔일수록 N(a)가 커져 보너스가 줄고, 오래 안 당긴 팔은 ln t가 자라며 보너스가 다시 커진다
이론값은 c = √2 ≈ 1.41 (UCB1) — 실제로는 더 작은 c가 잘 맞는 경우가 많음 · c = 0 이면 탐욕(greedy)

이번 걸음에서 비교한 값 (갱신 전)

Q(a)보너스실제 p

이번 걸음

팔별 선택 횟수 N(a)

좋은 팔에 몰리지만 다른 팔도 가끔 확인

누적 후회

Σ (p* − p_aₜ)

Thompson Sampling — 사후분포에서 하나씩 뽑아 가장 큰 팔을 고른다

→ 키: 다음 걸음
사전분포 p_a ~ Beta(1, 1) (균등) · 매 걸음 θ̃_a ~ Beta(α_a, β_a) 를 뽑아 aₜ = argmaxa θ̃_a
보상을 보면 α_a ← α_a + r , β_a ← β_a + (1 − r) … 성공은 α, 실패는 β에 1씩 더함 · 평균 = α / (α + β)

팔별 사후분포 Beta(α, β)

갱신 전선택한 팔의 갱신 후뽑은 θ̃실제 p

곡선 높이는 칸마다 맞춤. 많이 당긴 팔일수록 곡선이 좁아져 뽑는 값이 실제 p 근처에 모입니다.

이번 걸음

최적 팔 선택 비율 (누적)

지금까지 최적 팔을 고른 비율

누적 후회

Σ (p* − p_aₜ)

비교 실험 — 같은 환경에서 여러 번 반복해 평균

한 번의 실험은 운에 흔들리므로 반복 평균으로 비교

반복마다 보상 난수를 새로 뽑되, 같은 반복 안에서는 모든 알고리즘이 같은 난수표를 씁니다(공정 비교). ε·감쇠율·c는 2~3번 탭의 설정을 그대로 씁니다.

평균 누적 후회

직선으로 자라면 끝까지 손해 · 꺾이면 학습 성공
