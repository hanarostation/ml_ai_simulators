DQN (Deep Q-Network)

Q표 대신 신경망으로 Q(s,a)를 근사합니다. 브라우저에서 CartPole을 실제로 학습시키며 경험 재생(Experience Replay)과 타깃 네트워크(Target Network)를 빼면 학습이 어떻게 무너지는지 같은 seed로 비교합니다.

에이전트–환경 루프와 DQN의 부품

상태 = 파랑 · 행동 = 주황 · 보상 = 초록 · 가치(Q) = 보라 · 타깃 = 분홍 · 탐험 = 황토

CartPole 상태 s = (카트 위치 x, 속도 ẋ, 막대 각도 θ, 각속도 θ̇)는 연속값이라 Q표를 만들 수 없습니다. 그래서 신경망 Q(s,·;θ)가 상태 4개를 받아 행동 2개(← 밀기, → 밀기)의 Q값을 한 번에 내놓습니다. 매 걸음 보상 +1, 막대가 12°를 넘거나 카트가 ±2.4를 벗어나면 끝, 최대 500걸음.

브라우저용 축소 설정: 은닉층 32·32(파라미터 1,282개), 버퍼 50,000, 배치 64, 타깃망 복사 1,000걸음마다, 2걸음마다 1번 갱신, 처음 500걸음은 무작위 행동으로 버퍼만 채움, ε 1.0 → 0.05, Adam, Huber 손실, 입력 정규화(x/2.4, ẋ/3, θ/0.21, θ̇/3.5). 30,000걸음까지 길게 돌리면 500에 닿았던 수익이 다시 떨어지기도 합니다 — DQN의 대표적인 불안정성(과대추정·망각)이며, 다음 시뮬레이터 'DQN 개선판'이 다루는 문제입니다. 같은 seed면 같은 결과가 나옵니다. 왼쪽 시연은 학습과 별도로 지금의 Q망으로 탐욕(greedy) 행동만 해서 정책이 좋아지는 모습을 보여 줍니다.

수익 (최근 10 에피소드 평균)

Q 예측값 max Q(s₀) — 세로축 log₁₀

가로축 = 환경 걸음 수(0 ~ 설정한 걸음). Q 그림의 점선 = 이론 상한 log₁₀(Σγᵗ) — 보상이 매 걸음 1이므로 할인 수익은 (1 − γ⁵⁰⁰)/(1 − γ) ≈ 99.3을 넘을 수 없습니다.

경험 재생(Experience Replay) — 상관을 끊고, 다시 쓴다

연속한 전이는 거의 같은 상태라서 서로 강하게 상관되어 있습니다. 이런 표본으로 경사하강을 하면 한쪽 방향으로 계속 끌려갑니다. 버퍼에 쌓아 두고 무작위로 뽑으면 표본이 독립에 가까워지고, 한 번 겪은 경험을 여러 번 학습에 씁니다.

실험이 끝나면 전체 DQN 버퍼에서 직접 계산한 값이 나타납니다: 이웃한 두 표본의 막대 각도 θ 상관계수.

타깃 네트워크(Target Network) — 움직이는 과녁을 붙잡아 둔다

타깃 y = r + γ·max Q(s′,·)를 학습 중인 같은 망으로 계산하면, Q(s,a)를 올리는 순간 비슷한 상태 s′의 Q도 함께 올라 y도 같이 도망갑니다. 상태가 0.02초 간격으로 거의 같은 CartPole에서는 이 되먹임이 쌓여 Q가 이론 상한(≈99)을 훌쩍 넘어 발산합니다. 타깃망 θ⁻는 C걸음 동안 고정해 두었다가 복사합니다.

y = r + γ · maxa′ Q(s′, a′; θ⁻) (θ⁻ ← θ : C걸음마다)

화면 픽셀에서 바로 Q값으로 — Nature DQN (Mnih et al., 2015)

개념 설명 · 화면은 코드로 그린 Breakout 모양 예시 프레임

Atari에서는 상태가 게임 화면 그 자체입니다. 같은 DQN 알고리즘에 CNN을 붙이고, 화면을 줄여 4장씩 쌓아 넣습니다. 49개 게임에 같은 구조·같은 하이퍼파라미터를 썼다는 점이 핵심입니다.

  1. 프레임 건너뛰기(action repeat 4): 고른 행동을 4프레임 반복하고 그동안의 보상을 더함 → 결정 횟수가 1/4.
  2. 깜빡임 제거: 연속한 두 프레임의 픽셀별 최댓값을 씀(일부 물체가 짝수·홀수 프레임에만 그려지기 때문).
  3. 흑백·축소: 210×160 RGB → 밝기(Y) 채널 → 84×84.
  4. 4장 쌓기(frame stacking): 사진 한 장으로는 공이 어느 쪽으로 움직이는지 알 수 없음 → 최근 4장을 채널로 쌓아 속도·방향 정보를 줌. 입력 84×84×4.

Nature DQN 구조

행동 수

CartPole 망(이 페이지의 기본값)은 1,282개 파라미터, Nature DQN은 약 169만 개입니다. 그래도 학습 알고리즘(경험 재생 + 타깃망 + ε-greedy + 오차 자르기)은 완전히 같습니다.

보상 자르기(Reward Clipping)

게임마다 점수 단위가 제각각이라(벽돌 1점, 외계인 30점, 보스 200점 …) 한 학습률로 모든 게임을 학습하려고 보상을 부호만 남깁니다: 양수 → +1, 음수 → −1, 0 → 0.

대가: 큰 보상과 작은 보상을 구분하지 못함 (점수 200짜리와 1짜리가 같은 +1).

하이퍼파라미터 — Nature DQN vs 이 페이지
