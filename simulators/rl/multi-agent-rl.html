Multi-agent RL (MADDPG · QMIX)

여러 에이전트가 함께 배우면 서로가 서로의 환경이 되어 목표가 계속 움직입니다. 독립 학습의 비정상성, 중앙 학습·분산 실행(CTDE), VDN·QMIX의 가치 분해, MADDPG의 중앙 critic을 브라우저에서 직접 학습시키며 비교합니다.

다중 에이전트 루프 — 마르코프 게임

상태 = 파랑 · 행동 = 주황 · 보상 = 초록

공동 행동 (a₁, a₂)가 결과를 정합니다. 그래서 내 보상은 상대의 행동에도 달려 있고, 상대가 배우는 동안 내 입장에서 환경이 계속 바뀝니다(비정상성).

독립 학습자의 비정상성 — 서로를 쫓는 두 에이전트

그림을 누르면 시작 정책을 바꿉니다
설정
단계 0

가로 p₁ = P(에이전트 1이 첫 행동)세로 p₂ = P(에이전트 2가 첫 행동)회색 화살표 = 독립 기울기 방향
정책 확률 p₁(파랑) · p₂(주황)
에이전트 1이 보는 두 행동의 가치 차이 Q₁(첫) − Q₁(둘째) — 상대가 바뀌면 부호가 뒤집힌다

각 에이전트는 상대를 환경의 일부로 보고 자기 보상만 키우는 방향(정책 기울기)으로 움직입니다. 그런데 상대도 동시에 바뀌므로, 어제 좋던 행동이 오늘은 나빠집니다(가치 차이의 부호가 바뀜). 경쟁 게임에서는 두 정책이 서로를 쫓아 빙글빙글 돌고, 혼합(죄수의 딜레마)에서는 둘 다 손해인 (배신, 배신)으로 갑니다.

가치 분해 — VDN(합)과 QMIX(단조 믹서)

공동 행동을 모두 고르게 시도한 데이터(ε = 1)로 실제 학습
VDN: Qtot(s,a₁,a₂) = Q₁(s,a₁) + Q₂(s,a₂)   |   QMIX: Qtot = w₂(s)ᵀ · ELU( W₁(s)ᵀ [Q₁, Q₂] + b₁(s) ) + b₂(s),  W₁, w₂ = |하이퍼네트워크(s)| ≥ 0 → ∂Qtot/∂Qᵢ ≥ 0
둘 다 argmax Qtot = (argmax Q₁, argmax Q₂) — 각자 자기 Q의 최댓값만 고르면 팀 최선과 일치(분산 실행 가능)

읽는 법: 이 작은 문제에서는 세 방법 모두 대부분의 seed에서 결국 최적(7걸음)에 도달합니다. 차이는 학습 과정의 흔들림에서 납니다. 독립 Q는 각 로봇이 같은 팀 보상을 자기 Q에 통째로 귀속하고, 상대 위치를 볼 수 없어 상대가 배우는 동안 같은 관측의 결과가 계속 바뀝니다(비정상성) — 평가 결과가 바뀐 횟수가 가장 많습니다. VDN·QMIX-lite는 팀 TD 오차 하나를 두 로봇의 Q로 나눠 갖고, 목표값을 두 로봇이 모두 탐욕적으로 행동한다고 보고 계산해 덜 흔들립니다. 단 QMIX-lite는 믹서 가중치까지 함께 배우느라 가끔 실패하는 seed가 있습니다(seed 1~60에서 직접 계산: 바뀐 횟수 합 독립 Q 79·81·97, VDN 50·51·52, QMIX-lite 41·34·41 / 최적 도달 독립 Q 19·17·19, VDN 19·19·19, QMIX-lite 17·17·18, 20개씩).

MADDPG — 분산 행위자 + 중앙 critic (연속 행동)

simple_spread 축소판 · 브라우저용 축소 설정
critic: y = r + γ · Q′ᵢ( x′, μ′₁(o′₁), μ′₂(o′₂) ),   L = (Qᵢ(x, a₁, a₂) − y)²   (x = [o₁, o₂] 모두 봄)
actor: ∇θᵢ J = E[ ∇θᵢ μᵢ(oᵢ) · ∇aᵢ Qᵢ(x, a₁, …, aᵢ = μᵢ(oᵢ), …) ]   (행동은 자기 관측 oᵢ만으로)

두 로봇(파랑·주황)이 두 목표 지점(초록)을 나눠 덮어야 합니다. 팀 보상 = −(각 목표에서 가장 가까운 로봇까지 거리의 합) − 충돌 0.5. 행동은 2차원 속도(−1~1), 한 에피소드 25걸음. 관측 oᵢ = [자기 위치, 두 목표까지 상대 위치, 상대 로봇까지 상대 위치] 8개. 브라우저용 축소: 목표 위치 고정, 관성 없음, 은닉 32-32, 배치 32, 400에피소드.

critic 입력
로봇 1로봇 2목표 지점선 = 최근 평가 에피소드 궤적
–최근 평가 리턴
–무작위 정책
–직선 이동 기준
0갱신 횟수
에피소드 리턴 (이동평균 20, 점 = 평가) · 점선 = 무작위 / 직선 이동 기준
학습을 시작하면 배치의 첫 표본으로 계산한 숫자가 여기에 나옵니다.

독립 DDPG의 critic은 Q(oᵢ, aᵢ)만 봅니다. 팀 보상은 상대 행동에도 달려 있는데 그것을 볼 수 없으니, 상대 정책이 바뀔 때마다 같은 입력의 정답이 달라집니다(비정상성). MADDPG의 critic은 학습 때만 모든 관측과 행동을 보아 이 흔들림을 없애고, 실행 때는 행위자 μᵢ(oᵢ)만 씁니다. 이 작은 협력 과제에서는 차이가 작을 수 있으며, 에이전트가 많거나 경쟁·혼합 과제일수록 차이가 커집니다.

파이썬 코드 — 현재 설정 반영

PettingZoo MPE simple_spread 환경, PyTorch로 쓴 QMIX 믹서(하이퍼네트워크 + 절댓값 가중치)와 MADDPG 중앙 critic의 핵심 부분입니다. 격자 행동 순서는 이 페이지 기준 0↑ 1→ 2↓ 3← 4정지 입니다(Gymnasium FrozenLake는 0← 1↓ 2→ 3↑ 순서라 다름).
