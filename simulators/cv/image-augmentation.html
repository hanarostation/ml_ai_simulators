이미지 증강 시뮬레이터

회전·이동·확대, 밝기·대비·노이즈, Random Erasing·Mixup·CutMix를 흑백 의료영상에 직접 걸어 봅니다. 같은 설정에서도 뽑을 때마다 결과가 달라지는 실시간 증강, 학습에만 켜지는 Keras 증강 Layer까지 한 번에 확인합니다.

표시

의료영상 주의: 좌우 반전. 장기의 좌우 구분이 중요합니다(간은 환자의 오른쪽 = 화면 왼쪽, 심장은 왼쪽). 반전된 영상은 실제로는 드문 내장 역위 영상이 되어 라벨과 어긋날 수 있습니다. 노트북 설정도 좌우 반전은 뺐습니다.

과도한 회전. 환자는 대개 정해진 자세로 촬영되므로 ±° 같은 큰 회전은 실제로 나오지 않는 영상을 만듭니다. 노트북은 factor 0.03(±10.8°)만 썼습니다.

CT 밝기는 HU 단위. CT는 HU 값을 창(Window)으로 잘라 흑백으로 보여 줍니다. 밝기를 마구 흔들기보다 창의 중심·폭을 조금 흔드는 Window Jittering이 더 자연스럽습니다(강도 변환의 "감마·윈도 지터링").

역매핑 + 이중선형 보간

결과 영상의 픽셀을 눌러 보세요 (방향키 이동)

결과의 각 픽셀에서 거꾸로 "원본의 어디를 가져올까"를 계산합니다(역매핑). 회전·이동·확대/축소·반전은 하나의 아핀 행렬 M으로 합쳐지고, 소수 좌표는 주변 4픽셀을 거리로 섞습니다(이중선형 보간). 왼쪽 점선은 결과 화면이 원본에서 가져온 영역입니다.

실시간 증강(Online): 에폭마다 다른 변형

키보드 ← → 에폭 이동

같은 원본 한 장이 배치 안에서, 그리고 에폭마다 매번 다른 모습으로 모델에 들어갑니다. 모델은 같은 영상을 두 번 똑같이 보지 않습니다. 추론(training=False)으로 바꾸면 증강 Layer가 그냥 통과시킵니다.

증강의 3대 효과

① 데이터 확장

한 장을 여러 모습으로 바꿔 적은 데이터를 늘린 효과를 냅니다.

② 불변성 학습

조금 돌거나 밀리거나 어두워져도 같은 장기라는 것을 배웁니다. 위치·밝기 변화에 덜 흔들립니다.

③ 정칙화

매번 입력이 달라 훈련 데이터를 통째로 외우기 어렵습니다. Dropout·L2와 같은 계열입니다.

기법 세 계열

카드를 누르면 그 기법만 켠 채로 실험실이 열립니다

같은 원본에 해당 기법 하나만 적용한 모습입니다. 의료영상 적합도: 권장 주의 비권장

기하 변환 위치·모양을 바꿈 (픽셀값은 그대로)

강도 변환 픽셀값을 바꿈 (위치는 그대로)

영역 변환 일부 영역을 지우거나 다른 영상과 섞음

반드시 지킬 세 가지

1. 학습 데이터에만 적용. Train에만 증강하고 Validation·Test는 원본 그대로 둡니다. 평가까지 흔들면 성능을 제대로 잴 수 없습니다.

2. 증강은 새로운 정보가 아님. 이미 있는 영상을 비튼 것일 뿐, 새 환자나 새 병변을 만들지 않습니다. 데이터를 대신하지 못합니다.

3. 의료영상 주의. 좌우반전(장기 좌우 구분이 중요), 과도한 회전, CT 밝기는 HU 단위이므로 밝기 대신 Window Jittering.

모델 흐름: 증강 Layer는 Rescaling 앞

지금 설정으로 만든 Keras 코드

실험실에서 켠 기법과 세기가 그대로 들어갑니다. 노트북 5종(RandomRotation, RandomTranslation, RandomZoom, RandomContrast, RandomBrightness) 밖의 기법은 주석으로 안내합니다.
