ResNet 스킵 커넥션 시뮬레이터

층을 더 쌓았는데 훈련 오차가 오히려 높아지는 퇴화(degradation) 문제를, 입력을 그대로 더해 주는 지름길 y = F(x) + x 로 푼 것이 ResNet입니다. 잔차 블록 안을 들여다보고, 깊게 쌓았을 때 신호와 기울기가 어떻게 달라지는지 직접 확인합니다.

왜 x를 더할까: 항등 사상은 배우기 어렵다

H(x) = ReLU(W₂·ReLU(W₁x)) ← 이걸로 항등(출력 = x)을 만들려면
W₁, W₂가 정확히 '가운데 1, 나머지 0' 모양이어야 함 (초기값에서 멀다)

좌표계를 바꾸면: y = F(x) + x, F(x) = H(x) − x
항등 함수 ⇔ F(x) = 0 ⇔ 가중치 ≈ 0 (초기값에서 가장 가깝다)

잔차 블록의 기본값은 "아무것도 하지 않는 것"입니다. 위에서 s = 0 을 눌러 보세요. 잔차 블록은 출력이 x 그대로, 지름길을 끈 plain 블록은 출력이 0(정보 소실)이 됩니다.

ReLU는 덧셈 뒤에

표준: y = ReLU(F(x) + x) → F가 음수면 x를 줄일 수 있음
순서 바꿈: y = ReLU(F(x)) + x → F가 0 이상만 남아 더하기만 가능

이 예시의 F(x)는 '가장자리 강조분'입니다. 밝은 쪽은 더 밝게(양수), 어두운 쪽은 더 어둡게(음수) 고치려 합니다. ReLU를 덧셈 앞에 두면 음수 수정이 모두 잘려 어두운 쪽을 고치지 못합니다.

이 예시의 F(x)는 어떻게 계산하나요?

첫 3×3 합성곱이 채널 2개를 만듭니다: ① 가운데 1인 필터(그대로 통과), ② 3×3 평균 필터(흐리게). ReLU를 거친 뒤 두 번째 합성곱이 (①) − (②)에 가중치 크기 s 를 곱합니다. 즉 F(x) = s·(x − 흐린 x). 개념을 보려고 BN은 생략했습니다(가장자리 밖은 0으로 채움).
