하이퍼파라미터 튜닝 (Grid · Random · Bayesian Search)

당뇨 예측 모형(RBF 커널 릿지 분류기)의 C와 γ를 K겹 교차검증 점수로 직접 평가하면서, 격자 탐색 · 무작위 탐색 · 베이즈 최적화(가우스 과정 + 획득 함수)가 같은 평가 예산에서 최적점을 얼마나 빨리 찾는지 비교합니다.

하이퍼파라미터 튜닝 = 검증 점수를 돌려주는 블랙박스 함수 f(C, γ)의 최댓값 찾기. 기울기가 없고, 한 번 계산(평가)할 때마다 모형을 K번 학습해야 하므로 비싸다.

이 페이지의 모형 — RBF 커널 릿지 분류기

최소제곱 SVM과 같은 식
K(x, z) = exp(−γ · ‖x − z‖²)
α = (K + I / C)⁻¹ · y , y ∈ {−1, +1}
f(x) = Σᵢ αᵢ · K(xᵢ, x) → f(x) > 0 이면 당뇨로 분류
  • C가 크면 규제가 약해 학습 데이터에 딱 맞춤(과적합 쪽), 작으면 단순해짐.
  • γ가 크면 점 하나의 영향 반경이 좁아 경계가 구불구불, 작으면 거의 직선에 가까움.
  • 둘 다 10배 단위로 효과가 바뀌므로 로그 눈금(10⁻², 10⁻¹, …)으로 탐색한다.

데이터와 목적 함수 — K겹 교차검증 점수

seed 고정 생성 · 튜닝용 150명 + 독립 테스트 600명

획득 함수 세 가지

모두 최대화 · 표준화 y 단위
z = (μ̃(x) − f̃* − ξ) / σ̃(x)
EI(x) = (μ̃ − f̃* − ξ) · Φ(z) + σ̃ · φ(z) 기대 개선량
PI(x) = Φ(z) 개선될 확률
UCB(x) = μ̃(x) + κ · σ̃(x) 낙관적 상한

f̃* = 지금까지 최고 점수(표준화), Φ · φ = 표준정규 누적분포 · 밀도. 활용(exploitation) = μ가 높은 곳을 더 파기, 탐색(exploration) = σ가 큰 곳 확인하기. κ · ξ를 키우면 탐색 쪽으로 기운다 — 슬라이더를 바꿔 획득 함수 지도가 어떻게 퍼지는지 보세요.

실무 도구

대리 모형이 다를 뿐 반복 구조는 같다
  • scikit-optimize BayesSearchCV: GridSearchCV와 같은 사용법. 기본 대리 모형 GP(Matérn 커널, 길이 척도는 최대우도로 맞춤), 획득 함수 gp_hedge(EI · PI · LCB를 번갈아 씀), 초기 무작위 점 10개.
  • Optuna TPE: 점수 분포를 직접 모형화하는 대신, 좋은 시도 집합의 밀도 l(x)와 나머지 밀도 g(x)를 따로 추정해 l(x) / g(x)가 큰 곳을 고른다. 범주형 · 조건부 공간에 강하고 빠르다. 가지치기(pruning)로 가망 없는 시도를 일찍 멈출 수 있다.
  • 이 페이지의 GP는 신호 분산 1, y 정규화, 축별 길이 척도 ℓ₁ · ℓ₂(0.03~2, 최대우도 격자 탐색), 대각 잡음 σₙ² 로 직접 계산한다. 획득 함수는 41 × 41 격자 + 무작위 256점에서 고른 뒤 주변을 좁혀 가며 다듬는다.

튜닝도 과적합된다 — 검증 점수의 낙관 편향

고른 설정을 150명 전체로 다시 학습 → 독립 테스트 600명으로 채점

무작위 탐색: 평가를 늘릴수록 R개 seed 평균

교차검증 최고 점수 (고를 때 본 값)그 설정의 테스트 점수

중첩 교차검증 (Nested CV) 바깥 5겹 × 안쪽 4겹 무작위 탐색 15회

여러 설정 중 가장 높은 검증 점수를 고르면, 운 좋게 높게 나온 값을 고르는 효과 때문에 그 점수는 실제 성능보다 높게 나오기 쉽다. 튜닝에 쓴 점수를 최종 성능으로 보고하지 말고, 튜닝에 전혀 쓰지 않은 테스트 세트나 중첩 교차검증(안쪽 = 튜닝, 바깥 = 평가)으로 따로 잰다.
