    큰 그림: 지도학습 절차 6단계

    특성공학은 4단계 '학습' 안에서 fit 직전에 일어납니다
    1. 데이터 핸들링불러오기·정리·병합
    2. Y·X 지정y = 질환 여부, X = 나머지 열
    3. Train/Test 분할Test는 마지막 평가까지 잠금
    4. 학습특성공학 → fit (Pipeline)
    5. 학습·일반화 성능Train 점수와 Test 점수 비교
    6. 모델 구조화 → predict.pkl / joblib 저장 후 새 데이터 예측

    누르면 해당 화면으로 이동

    데이터 누수 — Test(또는 Validation fold)의 정보가 fit에 섞이면 평가 점수가 실제보다 좋게 나옵니다. 전처리 fit은 반드시 Train 부분에서만. → 3번 화면

    과적합 — 학습 성능 97% vs 일반화 성능 55%. 학습 데이터만 외운 모델은 새 데이터에서 무너집니다. 교차검증 점수로 판단하세요. → 4번 화면

    새 데이터 경로: 다시 fit 하지 않고 transform → predict

    Train→pipe.fit()→배운 규칙 (평균·표준편차·카테고리·선택 열·계수)→Test · 새 환자: transform → predict

    1번 화면의 설정으로 Train 12행에 fit한 파이프라인을 그대로 씁니다. Test의 결측값도 Train에서 배운 대치값으로, 표준화도 Train의 평균·표준편차로 계산됩니다.
