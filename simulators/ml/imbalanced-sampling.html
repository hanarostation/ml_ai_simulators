    반드시 지킬 것: 샘플링은 학습 데이터에만

    먼저 샘플링하고 나누면 데이터 누수입니다. SMOTE가 만든 합성 점은 검증·테스트 점을 재료로 삼을 수 있고, 복제한 점은 학습과 테스트에 똑같이 들어갑니다. 점수가 부풀려져 실제 병원 데이터(원본 분포)에서는 성능이 떨어집니다. 교차검증에서도 각 fold의 학습 부분에서만 샘플링해야 하며, 이를 자동으로 해 주는 것이 imblearn.pipeline.Pipeline입니다(fit 때만 샘플링, predict·score 때는 건너뜀).

    잘못: 샘플링 → 분할 (누수)

    전체 데이터정상 + 질환→ SMOTE.fit_resample(X, y)테스트가 될 점까지 재료로 사용→ train_test_split합성 점이 테스트에 섞임→ 점수 부풀림테스트 분포 ≠ 실제 분포

    올바름: 분할 → (학습 부분만) 샘플링 → 원본 분포로 평가

    전체 데이터→ train_test_split(stratify=y)→ Pipeline([scaler, sampler, model])학습 부분에서만 fit_resample→ 테스트 (원본 분포 그대로)샘플링 안 함 · 재현율·F1·balanced accuracy→ 활용
    학습 fold (위 주황 띠 = 여기서만 샘플링)검증 fold (원본 그대로)cross_validate(pipe, ...) 가 fold마다 자동으로 처리
