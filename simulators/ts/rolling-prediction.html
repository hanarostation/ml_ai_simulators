    규칙 정리
    
        
    
        
    무작위 K-fold — 학습 칸 중 빨간 칸은 평가 구간보다 미래입니다. "내일을 알고 어제를 맞히는" 셈이라 교차검증 점수가 실제 운영 성능보다 좋게 나옵니다.
    
        
    gap — 학습 끝과 평가 시작 사이를 비웁니다. 특성에 긴 롤링 창이 있거나, 예측 결과를 며칠 뒤에 쓰는 경우(보고 지연)처럼 경계 근처 정보가 섞일 때 씁니다.
    
        
    확장 vs 고정 — 확장 창은 데이터가 쌓일수록 학습이 길어지고, 고정 창(max_train_size)은 최근 패턴만 반영합니다. 구조가 자주 바뀌는 데이터라면 고정 창이 유리할 수 있습니다.

    h스텝을 어떻게 예측할까: 재귀 · 직접 · 다중 출력
    
        
    재귀 (recursive)직접 (direct)다중 출력 (MIMO)실제
    
      
    
      
    
        
    재귀 — 1스텝 모형 하나. ŷ(T+1)을 입력 창에 다시 넣어 ŷ(T+2)를 만듭니다. 모형은 하나지만 앞 단계 오차가 다음 입력으로 흘러 들어가 쌓입니다.
    
        
    직접 — h마다 모형을 따로 학습합니다 (y(T+j) ← 실제 lag). 오차가 되먹임되지 않지만 모형이 h개, 먼 h일수록 학습 행이 줄어듭니다.
    
        
    다중 출력 — 출력 h개를 한 번에 학습합니다. 목표 h개가 모두 있는 행만 쓰므로 직접 전략보다 행이 조금 적습니다. 선형회귀에서는 출력별 최소제곱이 독립이라 직접 전략과 거의 같습니다.

    실무에서는 새 데이터가 들어올 때마다 예측을 갱신합니다. 오늘 밤 내원 수가 집계되면 내일 예측을 다시 계산하고, 계수 재학습은 주 1회처럼 정해진 주기로 합니다. 한 번 예측(①)은 "평가 기간 끝까지 새 정보 없이 맞힌다"는 훨씬 어려운 문제입니다. 학습 끝 무렵의 특이값(예: 추석 직후)이 예측 전체에 남고, 예측 구간도 점점 넓어집니다. 두 방식의 오차는 서로 다른 문제의 점수이므로 섞어 비교하면 안 됩니다.
