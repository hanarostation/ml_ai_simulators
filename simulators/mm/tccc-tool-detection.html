[Case Study] TCCC 술기 도구 객체 탐지 및 판별 모형 시뮬레이터

박스 라벨만 있는 전술적 전투 부상자 처치(TCCC) 도구 영상에서, SAM 으로 박스를 윤곽 마스크로 승격하고 VLM 으로 이름 없는 클래스를 판별합니다. 점·박스 프롬프트, 자동 라벨링, 닫힌/개방형 어휘, 시각 질의응답, 지우기·붙여 넣기 생성과 검증까지 직접 조작합니다.

문제: 박스만 있는 도구 영상에서 "어디"와 "무엇"을 얻기

TCCC = 전술적 전투 부상자 처치 (Tactical Combat Casualty Care)

TCCC 응급처치 도구 객체 탐지 데이터(TCCC_Object_640)는 박스 라벨만 있고, 클래스 이름 정의 파일이 없어 class_0 ~ class_15 로만 되어 있습니다. 이 사례는 사람이 윤곽선을 한 번도 그리지 않고 마스크 라벨을 얻는 방법(SAM)과, 텍스트로 클래스를 판별하는 방법(VLM)을 다룹니다.

출발점: 앞선 실습에서 박스를 채워 만든 의사(pseudo) 마스크로 U-Net 을 학습했고, 클래스 이름은 crop 을 눈으로 보며 일부만 잠정 복원했습니다. 다음 단계는 박스를 SAM 프롬프트로 넣어 의사 마스크를 진짜 윤곽 마스크로 승격하는 것입니다.

    모의 마스크는 어떻게 계산되나
    모의 출력의 규칙
    
        
      
          
    • 점: 클릭한 곳의 색(5×5 평균)에서 시작해, 색 거리 < 허용치인 이웃 픽셀로 번져 나갑니다. 허용치 ×0.55 / ×1 / ×1.9 로 후보 3개(부분 · 물체 · 넓게)를 만듭니다.
      • 
          
    • 점(−): 그 점에서 번진 영역을 빼고, 점(+)과 이어진 덩어리만 남깁니다.
      • 
          
    • 박스: 박스 바깥 테두리 픽셀을 배경 표본으로 삼아, 표본과 색이 먼 박스 안 픽셀을 물체로 봅니다(작은 조각 제거).
      • 
          
    • 모의 자체 점수: 허용치를 조금 낮추고 높여도 마스크가 그대로인지(두 마스크의 IoU = 안정도). 실제 SAM 의 iou_scores 처럼 정답을 보지 않은 자기 평가입니다.
      • 
        
    
        
    IoU(A, B) = |A ∩ B| / |A ∪ B|　·　Dice(A, B) = 2|A ∩ B| / (|A| + |B|)
    
        
    자체 점수가 높아도 정답 IoU 는 낮을 수 있습니다. 압박 붕대처럼 배경(국방색 땅)과 색이 비슷한 도구, 쥔 손에 가려진 도구에서 확인해 보세요. 모형의 자기 확신은 검증이 아닙니다.

      VLM 으로 판별하기: 닫힌 어휘 vs 개방형 어휘
      모의 임베딩 · 점수는 실제 계산
      
      
      물체마다 모의 이미지 임베딩을, 질의마다 텍스트 임베딩을 두고 코사인 유사도를 계산합니다. 닫힌 어휘는 정해진 목록 안에서 softmax 로 반드시 하나를 고르고, 개방형 어휘는 질의마다 독립 점수를 임계값과 비교해 "없음"도 답할 수 있습니다. 질의 목록은 실습 노트북의 8개입니다.
      
      
      
        
        
        
      
      
      
      
      
      
        
      
          
      물체 하나 들여다보기 (현재 장면)
      
          
      
          
          
      cos(v, tq) = v·tq / (‖v‖‖tq‖)
      닫힌 어휘: pq = exp(cosq/τ) / Σj exp(cosj/τ)
      개방형: scoreq = 0.35·σ((cosq − 0.55)/0.08), 검출 = maxq score ≥ 임계값

      한계와 안전장치
      실습 노트북의 해석과 Review 를 정리
      
      
      
        
      SAM 마스크는 정답이 아니다
      박스채움보다 나을 뿐 또 다른 예측입니다. 규칙 필터(fill_ratio) 없이 그대로 쓰면 SAM 의 실패가 학습 데이터에 그대로 들어갑니다. 걸러진 것은 사람이 검수합니다.
      
        
      자기 확신은 검증이 아니다
      iou_scores 평균 0.875 는 SAM 이 스스로 매긴 점수입니다. 정답과 비교한 값이 아니므로 품질 보고의 근거가 될 수 없습니다.
      
        
      도메인 시프트 · 클립 종속성
      P05 촬영분만으로 학습한 U-Net 은 다른 시나리오에서 Dice 중앙값 0 으로 무너졌습니다. 평가는 클립·시나리오를 나누어 보고, 배치 현장의 촬영 조건을 포함해야 합니다.
      
        
      의료 영상에 SAM 을 그대로 쓰지 않는다
      연조직 경계 · 3D 볼륨 · 창(window) 설정 때문에 실패합니다. 도구 · 기구처럼 자연 영상에 가까운 대상에만 잘 듣습니다. 의료 영상은 MedSAM · SAM 2 계열과 별도 검증이 필요합니다.
      
        
      개방형 어휘는 탐색 도구
      텍스트로 클래스를 정의하는 검출은 후보를 좁히는 데 유용하지만 확정 근거로는 부적합합니다. 매칭 표로 클래스 이름을 확정하지 않고, 사람이 crop 을 보고 확인합니다.
      
        
      VLM 의 답은 최종 결론이 아니다
      환각 · 계수 오류 · 프롬프트 민감 · 근거 부재. 쓰더라도 초안 작성 · 검색 · 요약 보조로, 출력에 근거 영역(박스 · 마스크)을 함께 요구하고, 사람 확인 없이 기록에 남기지 않습니다.
      
        
      생성 데이터는 학습에만
      지우기 · 붙여 넣기 · 확산 모형으로 만든 영상은 검증 · 성능 보고에 넣으면 결과가 부풀려집니다. 합성본은 별도 모형으로 검증하고, 출처와 절차를 문서화합니다. 확산 모형은 허위 병변 · 재식별 위험이 있습니다.
      
        
      현장 처치 판단을 대신하지 않는다
      도구 탐지 · 판별은 교육 · 기록 · 라벨링 보조입니다. 부상자 처치와 임상 · 작전 판단은 훈련된 사람이 하며, 모형 출력은 사람 검토를 거친 참고 정보로만 씁니다.
      
      
      
    
      
    
      
      
      정리 (Review)
      실습 노트북
      
      
      
        
      주제핵심
      
        
          
      라벨 비용분류 : 박스 : 마스크 = 초 : 분 : 10분 이상 / 분할 라벨은 사람이 만들 수 없는 규모
      
          
      파운데이션 모델특정 과제가 아니라 넓은 입력에 대한 일반 능력을 대규모 사전학습으로 획득
      
          
      SAM 구조무거운 Image Encoder 는 이미지당 1회, 가벼운 Mask Decoder 는 프롬프트마다
      
          
      프롬프트점은 모호(후보 3개) / 박스는 모호성이 거의 없음 → 기존 검출 라벨 재사용
      
          
      마스크 승격SAM 마스크는 박스 면적의 약 30% → 박스채움 라벨은 전경을 3배 부풀렸음
      
          
      자기 확신iou_scores 는 모형이 스스로 매긴 점수이지 검증 결과가 아님
      
          
      자동 라벨링SAM 은 어디만 안다. 무엇은 박스가 알려 줌 / 필터 + 사람 검수 없이 쓰면 오류 전파
      
          
      의료 영상의 SAM연조직 경계 · 3D · 창 설정 때문에 그대로는 실패 → MedSAM · SAM 2
      
          
      개방형 어휘 검출탐색 도구로는 유용, 확정 근거로는 부적합
      
          
      VLM 의 답환각 · 계수 오류 · 프롬프트 민감 · 근거 부재 → 판별의 최종 결론으로 쓸 수 없음
