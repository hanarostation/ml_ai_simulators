환각(hallucination) — BLIP은 요추 영상에 무릎(knee)·경추(cervical) 같은 다른 부위와 있지도 않은 골절(fracture)을 붙이고, "mri mri mri …" 반복도 냅니다. 부위와 진단명이 둘 다 틀렸는데 문장은 완벽하게 자연스럽습니다. 모형은 "모른다"를 출력하도록 학습되지 않았고, 유창할수록 믿기 쉬워 더 위험합니다.

        
검색 방식 = 남의 환자 소견 — 텍스트 지표(ROUGE-1 0.799)는 가장 높지만 등급 정확도는 0.299입니다. 다른 환자의 소견을 그대로 붙여 넣은 것이므로 임상적으로 허용될 수 없습니다.

        
등급 불일치 — CLIP + 로지스틱 회귀 예측기의 정확도는 32.65%(무작위 25%)이고 0등급을 예측하지 않습니다. 템플릿 리포트는 문장이 아무리 반듯해도 예측만큼만 맞습니다.

        
텍스트 지표의 한계 — 숫자 하나가 바뀌어도 ROUGE-1은 0.8889로 거의 떨어지지 않습니다. BLEU·ROUGE·METEOR는 필요조건일 뿐입니다.

        
CLIP이 아는 것 — 양식(X-ray·MRI·CT)은 구분하지만 병변은 구분하지 못합니다. 유사도 절대값(0.2~0.35)은 의미가 없고 같은 영상 안에서의 순위만 의미가 있습니다.

        
데이터 누수·라벨 함정 — 영상 단위로 나누면 76명의 환자가 학습·검증에 걸칩니다. label_3class 의 값은 4종류입니다. 정답 리포트는 표에서 규칙으로 만든 단순한 판본이라 실제 판독문의 다양성이 없습니다.
