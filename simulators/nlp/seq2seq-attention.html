Seq2Seq · Attention 시뮬레이터

글자 단위 영→한 번역 모델을 이 페이지 안에서 직접 학습하고, 인코더 → 컨텍스트 → 디코더가 한 시점씩 어떻게 계산되는지 따라가 봅니다.

1데이터

한 줄에 한 쌍: 영어 | 한국어 (탭으로 구분해도 됩니다). 수정 후 데이터 적용을 누르면 글자 사전을 다시 만들고 모델을 초기화합니다.

전처리 규칙 (노트북과 동일한 생각)

인코더 입력
영어 문장을 글자 하나씩 one-hot (사전 크기 = 영어 글자 수 + PAD)
디코더 입력
SOS + 한국어 글자들  예) SOS 들 어 와 .
디코더 정답
한국어 글자들 + EOS  예) 들 어 와 . EOS
패딩
가장 긴 문장에 맞춰 0(PAD)으로 채우고, 마스크로 계산에서 제외 (인코더 상태 유지 · 손실 제외 · Attention 제외)

2학습 — Teacher Forcing

학습은 항상 Teacher Forcing: 디코더 입력으로 정답을 한 칸 밀어 넣고, 모든 시점의 손실(−log P(정답))을 한 번에 계산해 Adam으로 갱신합니다. 전체 문장을 한 배치로 사용합니다.

기본값 기준 한 모델당 보통 1~2분 · 손실이 0.05 아래로 내려가면 대부분 외운 상태
Seq2Seq 손실Attention 손실
입력정답Seq2Seq 생성Attention 생성
생성 열은 자기회귀(직전 예측을 다음 입력으로) 결과입니다. 학습 중 50 epoch마다 갱신됩니다.

3시뮬레이터 — 한 시점씩 따라가기

Teacher Forcing (학습 방식) — 디코더 입력 = 정답을 한 칸 민 것. 어느 시점에서 틀려도 그 시점 손실만 커지고, 다음 입력은 항상 정답입니다.
자기회귀 (추론 방식) — 디코더 입력 = 직전 예측. 정답이 없으니 한 글자씩 생성하고, 한 번 틀리면 뒤로 이어질 수 있습니다(노출 편향). 후보 글자를 클릭해 일부러 틀려 보세요.
먼저 ② 에서 모델을 학습하세요.

현재 단계 내부 값

실행하면 여기에 one-hot 번호, 은닉 상태 h·c, Attention 점수, Softmax 후보가 나타납니다.

Attention 가중치 α (디코더 시점 × 입력 글자)

Attention 모델을 실행하면 표시됩니다.
